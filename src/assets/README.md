# Assets Directory

Folder ini digunakan untuk menyimpan asset statis lokal seperti gambar, ikon custom, font, dan file media lainnya jika diperlukan di masa mendatang.

Saat ini, website dirancang menggunakan ikon dari paket `lucide` dan efek visual berbasis CSS murni (gradient, border, glassmorphism) sesuai spesifikasi yang diminta untuk memastikan performa yang sangat ringan dan cepat.

Jika ingin menambahkan gambar, Anda dapat meletakkannya di folder ini dan mengimpornya langsung di file JavaScript atau CSS.
